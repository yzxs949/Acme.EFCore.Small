轻量级 EFCore 通用操作类库

01快速开始

四步完成接入：安装包 → 建 DbContext → 配置连接串 → 注册服务。

安装

通过 NuGet 安装主包，包名为 Acme.EFCore.Small：

shell
dotnet add package Acme.EFCore.Small

随后安装对应数据库的 EF Core 提供程序，例如 Microsoft.EntityFrameworkCore.SqlServer。

创建数据库上下文

csharp
public class AppDbContext : DbContext
{
    public AppDbContext(DbContextOptions<AppDbContext> options) : base(options) { }

    public DbSet<User> Users { get; set; }
    public DbSet<Product> Products { get; set; }

单库模式 · IRepository<TEntity>

方法返回说明
Add / AddAsync—仅挂到上下文，需 Submit() 落库
AddNowSave / AddNowSaveAsyncint立即保存，返回受影响行数
GetInfoById / GetInfoByIdAsync实体或 null按主键查询
GetInfoDefault / GetInfoDefaultAsync实体或 null按条件取首条
GetList / GetListAsyncList<T>按条件取列表
UpdateNowSave / UpdateSaveAsyncbool更新并保存
DeleteNowSave / DeleteNowSaveAsyncbool删除并保存
AddManyNowSave / AddManyNowSaveAsyncint批量新增
UpdateManyNowSave / UpdateManyNowSaveAsyncbool批量更新
DelManyNowSave / DelManyNowSaveAsyncbool批量删除
Queryable() / Queryable(predicate)IQueryable<T>暴露查询入口，配合扩展方法
Any / AnyAsync · Count / CountAsyncbool / int存在性与计数
csharp
public class UserService
{
    private readonly IRepository<User> _repository;

    public UserService(IRepository<User> repository) => _repository = repository;

    public int Add(User user) => _repository.AddNowSave(user);

    public User GetById(int id) => _repository.GetInfoById(id);

    public List<User> Search(string name)
        => _repository.GetList(u => u.Name.Contains(name));
}

多库模式 · IRepository<TDbContext, TEntity>

当项目跨多个数据库时，注入时指定上下文类型，并配合该上下文的 IUnitOfWork<TDbContext> 提交。

csharp
private readonly IRepository<OrderDbContext, Order> _orderRepository;
private readonly IUnitOfWork<OrderDbContext> _orderUnitOfWork;

public async Task<bool> CreateOrderAsync(Order order)
{
    _orderRepository.Add(order);                    // 仅挂上下文
    return await _orderUnitOfWork.SubmitAsync() > 0; // 统一提交
}

工作单元

IUnitOfWork（单库）/ IUnitOfWork<TDbContext>（多库）负责提交与事务。 事务方法只在工作单元上，不在仓储上。

方法说明
Submit() / SubmitAsync()保存挂起的变更，返回受影响行数
BeginTransaction() / BeginTransactionAsync()开启事务（重复开启会抛异常）
CommitTransaction() / CommitTransactionAsync()提交事务并释放
RollbackTransaction() / RollbackTransactionAsync()回滚事务并释放
DbContext 属性当前关联的数据库上下文
csharp
public async Task ProcessOrderAsync(Order order)
{
    try
    {
        await _unitOfWork.BeginTransactionAsync();

        _orderRepository.Add(order);
        foreach (var item in order.Items)
            _orderItemRepository.Add(item);

        await _unitOfWork.SubmitAsync();
        await _unitOfWork.CommitTransactionAsync();
    }
    catch
    {
        await _unitOfWork.RollbackTransactionAsync();
        throw;
    }
}
⚠️

仓储的 Add / Update / Delete 只把变更挂到上下文，必须调用 Submit() 才会真正落库。

分页

ToPageList / ToPageListAsync 作用于 IQueryable<T>，pageIndex 从 1 开始。结果类型为 PageList<T>，含 Total 与 Items。

csharp
// 基础分页
public PageList<User> GetPaged(int pageIndex, int pageSize, string name)
{
    var query = _repository.Queryable(u => u.Name.Contains(name));
    return query.ToPageList(pageIndex, pageSize);
}

// 排序 + 分页
public PageList<User> GetPagedSorted(int pageIndex, int pageSize, string sortField, bool asc)
{
    var sorting = new Sorting(sortField, asc ? SortingType.ASC : SortingType.DESC);
    return _repository.Queryable()
        .AddSorting(sorting)
        .ToPageList(pageIndex, pageSize);
}

03查询扩展

全部位于 Acme.EFCore.Small.Extensions.LinqExtension，提供 Lambda 式 与 对象式（Condition / Keywords / Sorting）两套动态查询能力。

WhereIf · 条件过滤

条件成立时才追加 Where，避免拼接大量 if 分支。

csharp
var query = _repository.Queryable();

query = query.WhereIf(!string.IsNullOrEmpty(name), u => u.Name.Contains(name));
query = query.WhereIf(age.HasValue, u => u.Age == age.Value);
query = query.WhereIf(isActive.HasValue, u => u.IsActive == isActive.Value);

return query.ToList();

Condition 与 Symbol · 动态条件

用「字段名 + 值 + 运算符」描述条件，内部通过表达式树拼接，多个条件之间以 AND 连接。

csharp
public Condition(string field, string value, Symbol symbol)
public Condition()   // 无参，属性赋值
枚举值含义生成的比较
Equal = 0等于x.Field == value
NotEqual = 1不等于x.Field != value
GreaterThan = 2大于x.Field > value
LessThan = 3小于x.Field < value
GreaterThanOrEqual = 4大于等于x.Field >= value
LessThanOrEqual = 5小于等于x.Field <= value
Contains = 6包含（模糊）x.Field.Contains(value)
NotContains = 7不包含!x.Field.Contains(value)
StartsWith = 8以…开头x.Field.StartsWith(value)
EndsWith = 9以…结尾x.Field.EndsWith(value)
In = 10包含于列表list.Contains(x.Field)
NotIn = 11不包含于列表!list.Contains(x.Field)
IsNull = 12为空x.Field == null
IsNotNull = 13不为空x.Field != null
csharp
var conditions = new List<Condition>
{
    new Condition("IsActive", "true", Symbol.Equal),
    new Condition("Name", "张", Symbol.Contains),
    new Condition("Age", "18", Symbol.GreaterThanOrEqual),
    new Condition("Email", "a.com,b.com", Symbol.In)   // 逗号分隔列表
};

// 直接应用
var query = _repository.Queryable().AddConditions(conditions);

// 带开关：仅在 enabled 为 true 时应用
query = query.AddConditionsIf(enabled, conditions);
💡

In / NotIn 的 Value 使用逗号分隔（如 "1,2,3"）；IsNull / IsNotNull 无需传值。可空字段与枚举字段均已支持。

关键字搜索 · Keywords

对多个字段做「任一字段包含关键字」的 OR 模糊匹配，常用于列表页的全局搜索框。

csharp
// Name 或 Email 包含 "test"
var keywords = new Keywords(new[] { "Name", "Email" }, "test");
query = query.AddConditionsContains(keywords);

// 带开关重载
query = query.AddConditionsContains(hasKeyword, new Keywords(new[] { "Name", "Email" }, text));

动态排序 · Sorting

AddSorting 按字段名动态排序；传入 null 时回退按 Id 升序。字段不存在会抛 ArgumentException。

csharp
var sorting = new Sorting("Name", isAscending ? SortingType.ASC : SortingType.DESC);

query = query.AddSorting(sorting);      // 直接排序
query = query.AddSortingIf(needSort, sorting);  // 带开关

字段唯一值 · GetKey / GetKeyList

基于 GroupBy 提取指定字段的去重值，适合做下拉筛选项。

csharp
// IQueryable 场景
IEnumerable<string> cities = _repository.Queryable().GetKey(u => u.City);

// IEnumerable 场景
IEnumerable<int> ages = userList.GetKeyList(u => u.Age);

无跟踪查询

只读场景关闭变更跟踪，减少内存开销与提升查询性能。

csharp
List<User> list = _repository.GetListNoTracking(u => u.IsActive);
User user = _repository.GetInfoNoTracking(u => u.Id == id);
var listAsync = await _repository.GetListNoTrackingAsync(u => u.IsActive);

批量操作

csharp
// 批量新增 → 返回受影响行数
int rows = _repository.AddManyNowSave(users);

// 批量更新 → 返回 bool
bool updated = _repository.UpdateManyNowSave(users);

// 批量删除 → 返回 bool
bool deleted = _repository.DelManyNowSave(inactiveUsers);

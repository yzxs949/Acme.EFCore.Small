## 1. 测试概述

本报告记录对 `Acme.EFCore.Small` 主项目进行的单元测试与集成测试结果。测试覆盖主项目公开的全部核心能力：

- 实体 / 聚合根 / 值对象基类
- 仓储模式（`IRepository`）的同步与异步 CRUD / 查询
- 工作单元（`IUnitOfWork`）的提交与事务（提交 / 回滚）
- 分页（`PageList` 及 `ToPageList` / `ToPageListAsync`）
- 查询扩展（`WhereIf`、`Condition` + `Symbol` 全运算符、`Keywords`、`Sorting`、`AddConditionsIf`、`AddSortingIf`、`GetKey` / `GetKeyList`）

测试采用 **EF Core InMemory 提供程序** 进行真实仓储 / 工作单元集成验证，避免对外部数据库的依赖，保证可重复运行。
